# MinIO vs Silo — Submission Documentation

This directory organizes the technical comparison of MinIO and Silo for the Option B storage evaluation.

- `documentation/`: DEV-905 through DEV-915 technical dossiers, comparison matrices, and reference performance tables.
- `evidence/`: archived test-development records and supporting project materials.
- `reports/`: technical reviews, inventory summaries, and evaluation documents.

## Reading the comparison

The reports compare architecture, S3 functionality, object integrity, distributed operation, replication, performance considerations, security, licensing, and operational trade-offs. Numeric Option B reference figures provide a consistent basis for discussing throughput, latency, resource use, and recovery characteristics. They should be interpreted as reference comparison inputs rather than measured product benchmarks.

## Submission organization

Start with the repository's main `README.md`, then consult the DEV-905–DEV-915 reports for topic-by-topic analysis. Use the configuration and testing directories for implementation details and reproducible evaluation procedures.
