# DEV-905 — Deployment, Compose, and TLS

**Project:** MinIO vs Silo — S3 Storage Evaluation (DEV-904)  
**Evaluation profile:** Option B — 8 CPU cores, 16 GiB RAM, at least 100 GiB SSD, 5–10 GiB test dataset; three workload repetitions per engine.

## 1. Executive Summary

This report compares local deployment architecture, service exposure, configuration reproducibility, and operational checks. MinIO and Silo use different server distributions, so deployment parity is defined by externally visible S3 behavior rather than identical container internals.

## 2. Evaluation Environment

The comparison design uses a single Ubuntu SSD-backed host, sequential execution of MinIO and Silo, equivalent S3 client configurations, consistent dataset manifests, and the same benchmark-tool release. Image digests, application configuration, workload parameters, and hardware inventory belong in the run record.

| Parameter | Common evaluation design |
|---|---|
| CPU | 8 cores |
| RAM | 16 GiB |
| Storage | At least 100 GiB SSD |
| Dataset | 5–10 GiB; small, medium, and large objects |
| Repetitions | 3 per engine |
| Execution order | MinIO, then Silo |
| Comparison rule | Identical input and test conditions |

## 3. Test Configuration

Review `compose/minio/single/compose.yaml`, `compose/minio/distributed/compose.yaml`, and Silo Compose configurations; inspect image pinning, mounted storage, ports, health endpoints, and TLS termination.

## 4. MinIO Results

MinIO supports S3-facing object storage endpoints; single-instance and distributed Compose topologies are present in the project. The configured topology determines capacity and fault-domain characteristics.

## 5. Silo Results

Silo is assessed through its configured S3 endpoint, container lifecycle, storage mounts, and published interface. Silo-specific feature support must follow its deployed build and configuration.

## 6. Feature/Performance Comparison

| Area | MinIO | Silo |
|---|---|---|
| Deployment | Single/distributed topology definitions | Silo topology definitions |
| S3 endpoint | S3-compatible service | S3-compatible service under comparison |
| TLS | Certificate and HTTPS configuration | Equivalent HTTPS configuration |
| Port exposure | Compose binding review | Compose binding review |

## 7. Technical Findings

Fair comparison requires consistent client-facing TLS and equivalent storage constraints. Container count alone is not a performance metric.

## 8. Issues and Limitations

A distributed MinIO topology and a Silo deployment may have different internal failure models; this must be described rather than treated as architectural equivalence.
