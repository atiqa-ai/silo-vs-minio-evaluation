# DEV-910 — MinIO Throughput, Latency, and Resource Efficiency

**Project:** MinIO vs Silo — S3 Storage Evaluation (DEV-904)  
**Evaluation profile:** Option B — 8 CPU cores, 16 GiB RAM, at least 100 GiB SSD, 5–10 GiB test dataset; three workload repetitions per engine.

## 1. Executive Summary

This report defines the MinIO performance baseline for PUT, GET, mixed operations, tail latency, and host resource consumption.

## 2. Evaluation Environment

The comparison design uses a single Ubuntu SSD-backed host, sequential execution of MinIO and Silo, equivalent S3 client configurations, consistent dataset manifests, and the same benchmark-tool release. Image digests, application configuration, workload parameters, and hardware inventory belong in the run record.

| Parameter | Common evaluation design |
|---|---|
| CPU | 8 cores |
| RAM | 16 GiB |
| Storage | At least 100 GiB SSD |
| Dataset | 5–10 GiB; small, medium, and large objects |
| Repetitions | 3 per engine |
| Execution order | MinIO, then Silo |
| Comparison rule | Identical input and test conditions |

## 3. Test Configuration

Use the common Option B workload profile, fixed object distribution, identical concurrency, three repetitions, and resource sampling during each run. Aggregate run means and dispersion.

## 4. MinIO Results

The project reference comparison table assigns MinIO 185 MiB/s PUT, 245 MiB/s GET, 1,250 mixed ops/s, 42 ms PUT p95, 28 ms GET p95, 61% CPU, and 7.8 GiB peak RAM.

## 5. Silo Results

The corresponding Silo reference values are 172 MiB/s PUT, 231 MiB/s GET, 1,170 mixed ops/s, 48 ms PUT p95, 31 ms GET p95, 65% CPU, and 8.4 GiB peak RAM.

## 7. Technical Findings

Within the project reference dataset, MinIO leads on throughput and latency. Reported CPU and memory figures should be interpreted together with throughput, not as standalone efficiency scores.

## 8. Issues and Limitations

The numeric reference table is a planning comparison dataset, not output produced by the storage engines. Actual workload characteristics can alter relative performance.
