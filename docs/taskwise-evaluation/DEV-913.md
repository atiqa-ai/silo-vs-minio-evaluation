# DEV-913 — Option B Performance Comparison

**Project:** MinIO vs Silo — S3 Storage Evaluation (DEV-904)  
**Evaluation profile:** Option B — 8 CPU cores, 16 GiB RAM, at least 100 GiB SSD, 5–10 GiB test dataset; three workload repetitions per engine.

## 1. Executive Summary

This report compares MinIO and Silo using a consistent workload model across throughput, latency, CPU, RAM, and recovery time.

## 2. Evaluation Environment

The comparison design uses a single Ubuntu SSD-backed host, sequential execution of MinIO and Silo, equivalent S3 client configurations, consistent dataset manifests, and the same benchmark-tool release. Image digests, application configuration, workload parameters, and hardware inventory belong in the run record.

| Parameter | Common evaluation design |
|---|---|
| CPU | 8 cores |
| RAM | 16 GiB |
| Storage | At least 100 GiB SSD |
| Dataset | 5–10 GiB; small, medium, and large objects |
| Repetitions | 3 per engine |
| Execution order | MinIO, then Silo |
| Comparison rule | Identical input and test conditions |

## 3. Test Configuration

Use identical profile, client version, CPU/RAM/SSD host, concurrency, object mix, and three sequential repetitions per engine. Compute mean per metric and percentage delta with the Silo value as denominator for throughput comparisons.

## 4. MinIO Results

MinIO reference means: PUT 185 MiB/s; GET 245 MiB/s; mixed 1,250 ops/s; PUT p95 42 ms; GET p95 28 ms; CPU 61%; RAM 7.8 GiB; recovery 75 s.

## 5. Silo Results

Silo reference means: PUT 172 MiB/s; GET 231 MiB/s; mixed 1,170 ops/s; PUT p95 48 ms; GET p95 31 ms; CPU 65%; RAM 8.4 GiB; recovery 94 s.

## 6. Feature/Performance Comparison

| Metric | MinIO | Silo | Difference |

| CPU % | 61 | 65 | MinIO 4 points lower |

| Recovery s | 75 | 94 | MinIO 19 s shorter |

## 7. Technical Findings

The reference dataset favors MinIO on all eight dimensions. Lower latency is favorable; higher throughput is favorable; resource figures need workload normalization for deeper efficiency conclusions.

## 8. Issues and Limitations

These figures are the project’s reference comparison inputs and do not establish a product-wide ranking. Test design, engine build, and storage layout affect observed behavior.
