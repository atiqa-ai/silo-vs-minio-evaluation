**Target:** 8 CPU cores, 16 GiB RAM, >=100 GiB free SSD; four-node topology for distributed scenarios; 5–10 GiB dataset; three valid benchmark repetitions.

**Evidence categories:** `SOURCE-CHECKED` = content directly inspected from the project archive; `OFFLINE-REPORTED` = 85 passing tests and eight Compose validations reported by the user's Copilot session; `SCENARIO` = explicitly illustrative numerical dataset, not captured benchmark output. These categories must remain distinct.

**Method:** A successful parser or offline unit test demonstrates local implementation properties, not a live S3 endpoint, four-node resilience, or 16 GiB performance.

Each task dossier inventories exact source functions, test assertions, file hashes and evidence expectations.
