# Official Silo compatibility conditions

Source: https://silo.pgsty.com/compatibility/ (reviewed 2026-10-30). Each condition needs an APPLIES or DOES_NOT_APPLY decision with evidence, not an assumed PASS.

| ID | Official category | Evidence required | Decision |
|---|---|---|---|
| O01 | Installation and startup | Container images, services, paths, permissions | REVIEW REQUIRED |
| O02 | Custom authorization policies | Allow/Deny, version deletes, source IP and proxy trust | REVIEW REQUIRED |
| O03 | Older auth and notification settings | OIDC, legacy database notifications, TLS/env files | REVIEW REQUIRED |
| O04 | Programs relying on old bugs | Invalid requests, If-Match, multipart listing and exit codes | REVIEW REQUIRED |
| O05 | Custom clients and administration tools | Private APIs, signed headers, Console and Go modules | REVIEW REQUIRED |
| O06 | Multi-pool operations and retired strict multipart mode | Pool write/delete and strict listing settings | REVIEW REQUIRED |
| O07 | Replication, mixed versions and rollback | IAM revocation, configuration state, backups and coordinated versions | REVIEW REQUIRED |
| O08 | Self-update and upstream online services | admin update, mcli update and SUBNET dependencies | REVIEW REQUIRED |
