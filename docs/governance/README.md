# Repository governance

- Build and validate locally before GitHub publication.
- Task-prefixed local commits; no remote until approved.
- Never commit real credentials, private keys, internal identifiers or production data.
- Redact evidence and screenshots before publishing.
- Large artifacts need an approved LFS/external policy.
- Destructive cleanup requires explicit approval.
- No tests or phases marked complete without raw evidence.
- LICENSE selection deferred to licensing review.
